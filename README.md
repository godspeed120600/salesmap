# 세일즈맵 (salesmap)

주소 목록을 카카오 지도 위에 띄우는 모바일 웹페이지. 핸드폰 브라우저로 열고 "홈 화면에 추가"하면 앱처럼 씁니다.

- 페이지: https://godspeed120600.github.io/salesmap/
- 데이터: 구글시트 (`index.html` 의 `CONFIG.SHEET_CSV_URL`) — 컬럼 `이름, 주소, 위도, 경도, 인허가일자, 업태, 업종, 메모`
  - `위도/경도`가 비어 있으면 `주소`로 자동 지오코딩 (결과는 브라우저에 캐시)
  - 시트 수정 → 페이지 새로고침이면 끝. 재업로드 불필요
- 마커 탭 → 카카오맵 앱으로 열기 / 길찾기 / 주소 복사
- `업태` 값별로 색상·필터 칩 자동 생성

## 카카오 개발자 콘솔 설정 (필수)
1. 앱 설정 › **카카오맵 › 활성화 ON**
2. 플랫폼 › Web › 사이트 도메인에 `https://godspeed120600.github.io` 등록 (로컬 테스트용 `http://localhost:3000` 도 함께)

## 로컬 테스트
`serve.ps1` 실행 후 http://localhost:3000 (같은 와이파이의 핸드폰에서는 PC IP:3000)
